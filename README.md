# North End Creamery redesign concept

A responsive React and Vite website concept for North End Creamery in Boston.

## Run locally

```sh
pnpm install
pnpm run dev
```

Vite prints the local preview URL in the terminal. Build for production with `pnpm run build`; the output is written to `dist/`.

## Content and imagery

The official site was unavailable during research. The address and homemade-ice-cream description are based on the North End Chamber of Commerce listing. Flavor names were taken from Boston University coverage; selection can change, so the page says to check with the shop. The hours and phone number are intentionally omitted because the available listings conflict or are not verified.

Shop imagery is linked from the North End Chamber listing; editorial ice-cream photography is from Unsplash. This is an independent redesign concept and is not the official business website.
