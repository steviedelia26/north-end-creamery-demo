# Morrow Creamery — fictional website concept

A responsive React and Vite demo for a fictional neighborhood ice cream shop inspired by Boston. Its name, location, and sample flavors are illustrative and do not describe a real business.

## Run locally

```sh
pnpm install
pnpm run dev
```

Build for production with `pnpm run build`; output is written to `dist/`.

Photography is sourced from Unsplash. The shop identity and Harbor Quarter location are fictional.
